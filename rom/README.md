# Place your ROM here

This folder is intentionally empty and git-ignored.

The tools need a copy of the Japanese ROM that **you legally own**. The repo
does **not** and **will not** include it (see [../DISCLAIMER.md](../DISCLAIMER.md)).

Two ways to point the tool at your ROM:

1. **Environment variable** (recommended):
   ```bash
   export RUDRA_ROM="/path/to/Rudra no Hihou (Japan).sfc"
   ```
2. **Drop it in this folder** as:
   ```
   rom/Rudra no Hihou (Japan).sfc
   ```

Reference (the clean Japanese cart, headerless, 4 MB / 32 Mbit, HiROM):
- internal title region "RUDORA NO HIHOU", maker `C3` (Square), product `AOR`.
